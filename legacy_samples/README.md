# V6 示例迁移资料

用户已确认原网站内容全部是示例，授权调整结构。原页面和媒体保留在 originals/，该目录位于 frontend 静态根目录之外；绝不能给它配置 Nginx alias。新页面只读取公开 API，不回退原始正文。

manifest.json 含经过替换的虚构候选资料，apply 只生成草稿、不会创建用户或自动发布。inventory.json 逐条记录原路径、SHA256、离线来源及处置。旧图片/PDF 已移出静态目录，原 URL 应为 404；获准重新使用的媒体须经过上传校验，并由当前获批版本引用后从受控 URL 提供。

真实环境导入前先 dry-run、审阅报告并提供现有管理账号 ID 和新批次 UUID；成员需显式认领/绑定，由本人提交公开授权并由其他合格人员审核。示例论文/项目等需人工添加明确匹配的贡献者与证据确认。不要按姓名自动关联或创建默认密码。部署、导入、回退步骤见 docs/legacy-migration.md。
