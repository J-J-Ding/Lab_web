# V8 统计口径 v8.1

所有公开指标从 V6 public selectors 出发，使用当前 PUBLISHED 指针及即时 gate，响应 no-store。共同成果按 ContentItem UUID 去重，不按作者或项目关联行数计数；成员人数按公开档案 UUID、批准版本身份与 ACTIVE/ALUMNI 状态计算，不按账号角色或内部成员资格计算。

论文按发表日期、项目按立项日期、竞赛按获奖日期、活动按上海时区开始日期、新闻/博客按事件日期、刊物按出版日期分年。未知日期计入总量，单列 unknown_date，不放入年度柱图。年度范围最多20年，1900–2200；增长基期0返回 null，界面显示“无可比基数”。固定实验室介绍不参与科研成果分类总量。

公开人数是当前可公开人数，不推算缺乏变更历史的历年人数。成员参与和项目输出仍来自原关系；同一成果可在多名成员/多个项目各出现一次，不能将这些分组直接相加当作全站唯一量。

内部运营统计仅 ROOT/ADMIN/TEACHER 可见。私密成员档案按既有管理范围过滤，ADMIN 可看本人但不能借统计枚举其他 ADMIN/ROOT。审核提交事件和最终决策事件分别计数；耗时以服务器记录的提交至决策差值计算，返回样本量、中位数/P95秒数，撤回/未决不进入样本。所有管理角色允许自审，仍保留真实审核记录。

导出受管理权限和限流约束，当前只导出公开成果白名单字段 id/kind/title/summary，最多10000行，UTF-8 BOM CSV。公式/控制字符开头转义，审计仅字段、条数和筛选摘要，不保存数据正文。公开聚合不含用户数、待审数量、内部经费和联系方式。

内部内容对象数按对象创建年份筛选，审核事件按审核/提交事件发生年份筛选；它们与公开成果业务日期口径不同，不能直接作同一漏斗分母。category在工作/公开版本白名单类型字段中筛选，内部结果不开放任意ORM维度。
