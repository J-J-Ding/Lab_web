## 页面和安全行为

- 三页复用官网深色导航、logo、科技蓝、浅色背景与移动端换行布局；新CSS作用域为auth页面和账号入口。
- 注册真实调用V2，默认Customer，无自动登录；重复用户名/弱密码/确认密码不一致均有提示。登录成功通过me确认Session再进入个人中心。
- 导航异步加载账号入口；根目录、栏目和深层详情路径均验证，保留原激活态/栏目。退出按钮通过POST，不用GET退出。
- 个人资料只提交first_name/last_name/email；用户名和身份只读。ROOT标志优先，其余四种角色显示来自真实API，前端不授予权限。
- 每次写请求读取最新CSRF Cookie，使用X-CSRFToken和same-origin凭据；登录后使用轮换值。未保存密码/Session到localStorage、sessionStorage或URL，不读取HttpOnly sessionid。
- 接口消息用安全DOM/textContent，姓名中HTML片段不会执行；错误字段有aria-invalid/aria-describedby和错误焦点。
- 403区分会话失效与CSRF错误，不自动重放写请求；429和服务异常有提示，退出失败不会假装成功。
- 同一身份恢复焦点时保留未保存的资料草稿；身份改变清除旧资料。写入后使旧查询失效再读取真实结果；pagehide清空资料/密码并使请求失效，pageshow重新核验。
- BroadcastChannel仅通知会话变化，收件页仍查询后端，不发送账号资料或凭据；退出后其他标签页和浏览器后退不显示旧资料。
