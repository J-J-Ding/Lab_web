# V16 科研图文正文实施与验证

对应 `specs/V16-科研内容图文编辑与正文图片展示.md`，用户已批准并追加“技术文章”改“技术博客”。开发目录 `/opt/Lab_web`，分支 `arc-update`。

## 实现

- 本地托管 Tiptap 3.33.0（MIT）及开源 StarterKit、Table、TextAlign，esbuild 0.25.12构建；无CDN、云编辑器账号或商业组件。源码、package-lock、构建产物和运行依赖许可证一起提交。构建方式见 `frontend/editor-src/README.md`。
- ContentRevision 新增可空 rich_body JSON；`0012_contentrevision_rich_body` 迁移。保存与历史恢复创建完整版本；旧客户端未传该字段时保留原正文。旧工作流克隆也保留正文；当前业务继续直接保存生效，未恢复退休审核接口。
- 正文支持标题、粗斜体、下划线、列表、引用、对齐、安全链接、基础表格、撤销重做及预览；新增内容类型共用正文，原有元数据与署名权限不变。
- 正文图片在光标处插入，支持宽度25/50/75/100%、左右／居中、图注及移除；单图沿用5 MiB限制。文字50,000、图片30张、表格20×10、JSON500 KiB、节点数及深度均受限制。
- 图片保存资产ID，后端检查归属／历史引用、图片类型、扫描、过期与删除状态，并自动建立RevisionAsset引用。正文与普通附件合计最多60个，保留30图加原有30附件的容量。
- 官网和团队预览均使用白名单DOM渲染，不注入用户HTML；图片地址由当前权限接口返回，草稿／内部图片不会因正文链接公开。已删除标记的图片也不再由公开／站内图片接口提供。
- 历史正文按纯文本载入，尖括号保留为文字。新正文与旧body副本只展示一次，正文图片不重复出现在附件区。仅带本地资产标记的图片HTML可往返，外部普通img不会被导入。
- 修复原表单标题／摘要label缺少闭合导致正文点击焦点被摘要抢走的问题；所有现用布局资源更新缓存键，导航和分类统一“技术博客”。

## 部署与回退

本次仅开发和隔离验证，不合并main、不变更正式后端镜像、不执行正式数据库迁移或上线。按AGENTS.md，需用户验收后再同步运行版本。

部署时先备份数据库与私有文件，使用同一代码版本构建后端，执行0012迁移和常规运行角色授权检查，再更新后端和前端。前端依据后端`rich_content`能力开关启用图文编辑；旧后端仍显示原文字编辑栏，避免前后端未同步时发送未知字段。

回退保留新增列、文档和文件引用，不做破坏性反向迁移。出现问题优先关闭新编辑入口并保留读取；不得让旧客户端覆盖新正文。现有普通成员资料、Word简历、简历投递、SMTP和域名配置均未改变。

本期不支持Word文件导入、数学公式、打印分页、复杂绕排、合并单元格和多人实时编辑；Word／网页粘贴只保留支持的格式，外部图片需通过系统重新上传。
