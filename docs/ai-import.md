# V7 AI 文档助手

入口：个人中心/工作区的“AI 文档助手”，`/ai-import.html`。支持有文本层PDF、DOCX≤20MiB；扫描PDF明确提示需要OCR/手工录入。所有原件专用 purpose=ai_source、PRIVATE，不供公共下载，不自动作为公开附件。

流程：上传并同意本地解析→worker解析→展示脱敏文本→选择连续片段并明确同意发送至DeepSeek→候选与逐字段来源证据→编辑候选→选择并确认字段→保存草稿。不会自动发布、审批、创建账号、授予权限或按同名绑定贡献者。多成果最多10条候选，分别显式保存；已有标识显示可见匹配，不自动合并。作者必须人工选择已有可见贡献者；没有匹配先到原内容流程建立外部署名。

CUSTOMER只能导入本人资料，其他内容仍要求正式投稿资格；Session/CSRF和锁内权限复核沿用原系统。目标草稿版本过期409，候选保留；相同应用请求幂等，不会重复建稿。摘要生成以用户明确核实字段为输入、单独消耗额度，摘要只应用到已有草稿。

API：GET/POST `/api/ai/imports/`；GET/DELETE `/api/ai/imports/{id}/`；POST `consent/`（新增明确远端授权）、`cancel/`、`apply/`；PATCH `candidate/`；GET `matches/`；POST `/api/ai/summaries/`；GET `/api/ai/quota/`。对象只对owner可见，不能以管理员身份批量读取他人简历。返回脱敏错误码，不含key、原始请求/供应商错误正文。

首次创建 consent_version=local-v1，只授权本地解析；远端授权必须 deepseek-text-v1、最新lock_version、text_digest与用户选中脱敏原文。源证据需引用对应页和选中片段；未知字段/权限字段拒绝，无证据生成字段不能直接进入候选。人工修改标记不确定，保存仍要求逐项确认。

原件7天、候选30天、账本最小元数据180天；处理中和已引用业务数据不级联删除。取消不保证撤回已发送处理，UNKNOWN计费保留预算不重发；备份和第三方副本不承诺立即擦除。服务关闭时手工录入继续可用。
