# V12 实施记录

方案：`specs/V12-资料编辑回收站与功能页面完善.md`。用户于2026-11-06批准执行，随后批准统一个人资料、条件毕业去向及Teacher投递通知的修订。工作目录始终为`/opt/Lab_web`，分支`arc-update`。

## 当前实现

- 各身份共用个人资料，末尾上传私有PDF/DOCX简历；旧resume入口跳转到该栏。Customer可保存本人资料，仍无团队编辑权限。团队成员可从合法当前参与成果生成Word。
- 毕业去向仅ALUMNI时显示；切换状态保留旧数据，但非ALUMNI不返回公共去向，也不能通过毕业年份筛选推断旧年份。
- Customer预览已保存资料后明确确认投递；持久化个人资料、简历文本及文件引用快照。后续编辑不改写旧投递；数据库触发器禁止篡改快照及物理删除投递历史。
- 有效Teacher/Root接收站内通知，显示未读数，按收件人独立标记已读；前台每30秒在可见页面刷新。点击查看资料快照、预览PDF或下载DOCX。Student/其他Customer无权查看；Teacher不能浏览任意访客档案或直接使用普通资产链接获取访客文件。撤回后Teacher详情/文件拒绝，Root保留审计查看。
- 内容软删除/回收站、版本检查、恢复默认不公开；公共列表/详情、首页、成果关系、统计、AI重复提示及文件门禁排除已删除。共享文件的其他有效公开引用继续可用。
- 增加PATENT类型、详情、发明人关联、图统计、公共列表/详情及编辑器支持，扩展数据库类型/图/日期触发器；contact_email只在团队页面详情增加。
- CV私有技能、政治面貌、教育补充、实习/实践及本人职责；按稳定贡献关联生成，不按姓名匹配。受控OOXML模板处理跨run占位符与重复段落，隐藏空章节，按选择排序；TEAM成果须主动选入并确认，过滤他人成果/已删除成果，不输出项目经费。
- 六张主图：论文、项目、竞赛、荣誉、专利、出版成果，桌面3列/手机1列，竖向柱状图和折叠数据表；新闻/活动/资源保留补充统计。内部看板保留明确标注的历史审核指标。
- 移除栏目箭头并保留桌面悬停/键盘子菜单、手机一级链接。联系页修正标题、空态、招聘邮箱待配置、身份对应投递入口和管理编辑入口。AI说明固定显示，未登录/禁用/额度异常仍有手工入口，操作保持禁用。
- 新设密码统一6至128位、仅英文字母与数字且两者都含；注册/改密/Root重置/初始化命令共用验证，现有含符号密码仍可登录。
