# V6：官网动态化与个人主页自动生成

- 状态：待评审；依赖 V5 可用的审核与发布指针。
- 当前目录 `/opt/Lab_web`、分支 `arc-update`；共同安全、验收和发布门禁见[总体规划](V4-V9-后续开发总体规划与验收基线.md)。

## 1. 目标、现状与范围

现有九个静态栏目、深层详情 URL、图片和成员成果脚本必须保留外观及链接兼容。V6 将公开查询切换到数据库，成员主页按参与关系自动汇总，不再多份录入。包括出版刊物、毕业去向、固定实验室介绍；不引入 React/Vue 或重建 Nginx，不提前接入 AI/看板。

先公布 API 和文件访问规则，后迁移一小批资料，再逐栏目切换，不能一次导入就删除全部旧页面。图片/文档属于媒体资产，不直接从旧目录搬走导致旧链接失效。

## 2. 公共 API 与展示规则

| 路径（GET） | 返回范围 | 筛选 |
| --- | --- | --- |
| `/api/public/members/`、`members/{slug}/` | 已发布public_member_status为ACTIVE/ALUMNI且privacy_gate允许的档案 | 成员类型、方向、在组/毕业、年份 |
| `/api/public/members/{slug}/achievements/` | 本人参与的可公开发布成果 | 类型、年份、分页 |
| `/api/public/content/`、`content/{uuid}/` | 只读已发布且未撤下对象 | kind、year、category、q、page |
| `/api/public/projects/{uuid}/outputs/` | 关联该项目且双方均可公开的成果 | 类型/年份 |
| `/api/public/graduates/` | 同一成员库的可公开毕业去向 | 年份/学位 |
| `/api/public/pages/{key}/` | 固定 home/about 的已发布快照 | 不接受任意文件路径 |

统一 published selectors，不能在各页分别写 `state != DRAFT`。匿名响应不含内部经费、账号邮箱、私密联系方式、草稿数量、审稿意见或资产真实路径。个人中心“我的投稿/参与/待审”调用私有 API，不复用公共接口加 `include_private=true`。

默认分页 20、最大 100、稳定按业务日期+UUID 排序；q 长度 2–100、白名单排序，先 PostgreSQL ILIKE + 必要全文索引，实测再用 pg_trgm；如需扩展必须在迁移与权限文档中明确，不另建搜索集群。搜索同样只索引发布字段，不能先搜全表再前端过滤。

公共读缓存初期不超过 60 秒；提交审核不失效公共缓存，发布/撤下/隐私撤销在事务提交后清除相关对象、成员主页和列表缓存。撤下和隐私撤销必须立即失效且不继续下载，所有公共选择器/下载共同检查即时visibility/privacy gate，不修改不可变发布快照；不能容忍 TTL 期间泄露。缓存键含筛选/分页/公开版本；私有 API 默认 no-store。

## 3. 原 URL 与页面改造策略

- 保留 `frontend/data/{papers,projects,competitions,publications,members,graduates,activities,news,blogs}/index.html`，用统一列表脚本读取相应 API。
- 通用详情可采用 `frontend/content.html?id=<uuid>` 和 `frontend/member.html?slug=<slug>`；旧深层 `index.html` 作为兼容入口按映射读取同一公开对象，不从 URL 拼接本地读文件。
- 迁移清单必须逐个分类旧HTML/PDF/图片等为“继续公开、替换兼容入口、迁入私有、撤除/安全占位”；离线备份不等于继续公开。当前frontend被Nginx直接读取，需在切换时移出敏感原文件与含原正文HTML到不被服务的备份区，已迁移正文替换为安全兼容壳，防止API撤下而原文件仍可直读。旧媒体若不能保留公开，原URL必须返回拒绝/不存在或无敏感内容占位；授权后逐条验证原始URL，不只测新接口。
- LegacyURLMap 保存旧规范路径、目标内容/成员、迁移批次和校验摘要；逐一验证中文、空格、编码与大小写，禁止开放跳转和 `../` 路径穿越。
- 成员 slug 变更保留 alias，旧成员 URL 仍可访问；已撤下对象返回统一不存在，不能回落到旧静态内容。
- API 暂不可用时显示错误/重试和原导航，不默默返回过时私密内容；未迁移栏目仍保持静态。栏目级开关明确迁移状态，不能每次网络失败自动切回旧静态版本。
- 首屏/加载/空结果/错误/分页有清楚状态；安全 textContent，受限 Markdown 经服务端清洗；已有成员论文脚本逐步适配统一源，避免双重加载。

## 4. 附件和图片管理

上传 multipart 必须配置 DRF MultiPartParser/FormParser 与现有 JSON parser 并存，保持 Session/CSRF。用户默认单文件 20 MiB、头像/图片 5 MiB，白名单 JPEG/PNG/WebP/PDF/DOCX；上传先入私有隔离区，检查后缀+MIME+魔数、路径、图片解码、DOCX ZIP 展开预算和 SHA256，拒绝 HTML/SVG/脚本。未经安全校验不得公开。

`POST /api/assets/` 返回私有 UUID；`GET /api/assets/{uuid}/download/` 经权限检查，使用安全下载文件名与 nosniff。公开图片/附件仅当其被当前发布版本引用且 asset.visibility=PUBLIC、检查通过，才允许公共读取。私有简历、证明和 AI 文件永不以通用 media alias 暴露。

系统 Nginx 后续如需 X-Accel-Redirect，仅配置 `internal` 私有 location，由 Django 先授权；本阶段先实现 Django 授权流式下载即可，性能达到阈值再评审 Nginx 配置。公开文件禁止目录列表。缩略图同样沿用父资产权限，不让缩略图绕过撤下。

Asset 只有 owner 能申请删除；仍被历史/当前版本引用时不物理删除，先取消新引用，按保留策略回收孤立文件。清理任务需 dry-run 和最小保留期，避免数据库回退后文件已经消失。

## 5. 静态资料迁移方案

新增 ImportBatch、ImportRecord、LegacyURLMap；迁移清单字段：源路径/哈希、类型、候选 UUID、归一标识、关联匹配、公开授权、附件、错误、处理结果。文档内静态公开信息不意味着允许公开账号私人字段；历史手机号/email 需人工确认，默认不迁移到公共输出。

拟提供命令：

```bash
python manage.py import_legacy_content --manifest <清单路径> --dry-run --report <私有报告路径>
python manage.py import_legacy_content --manifest <清单路径> --apply --batch-id <审核过的批次>
python manage.py verify_legacy_import --batch-id <批次UUID>
```

以上为待实现命令，不是当前可运行命令。先在测试库演练：①扫描只读清单；②人工审重/作者匹配与隐私确认；③幂等创建草稿和资产；④按 V5 审核发布；⑤校验数量/链接/作者顺序/媒体；⑥切换栏目开关。重复 apply 同批次不得重复写；源哈希变化要产生新的待审版本，不能静默覆盖。未经授权不创建真实账号或给成员分配默认密码。

不能自动按重名认领成员/作者。DOI/ISBN/项目编号冲突暂停对应条目，失败不抹掉成功批次；记录可重试边界。最先试点论文+两名成员，再扩展项目、竞赛、出版刊物、活动、新闻、博客和去向。

## 7. 必须实际执行的验收

执行共用 check/迁移/完整 Django/全部浏览器测试，新增：

- 一篇论文关联三名成员并审核发布，论文列表、三人主页、项目成果一致更新且 UUID 相同；待审新稿不改变任何公共页面。
- 搜索/分页/筛选不返回 DRAFT/REJECTED/撤下内容、内部字段或无权限项目标题；无结果和 API 503 正确呈现。
- 成员教育/去向隐私切换、撤下成果后列表/主页/缓存/附件全部立即收紧。
- 原九个栏目、深层中文/空格 URL、头像和允许公开的 PDF 可用；已经迁入私有/撤下的旧正文、原PDF、原图片直链均不能绕过权限；导入前后逐条清单对账，不只比较数量。
- 重跑导入零新增重复；同名作者不自动绑定；损坏文件/超限/伪装后缀/ZIP 炸弹/路径穿越/跨用户下载被拒；CSRF 缺失上传失败。
- 桌面1440、平板768、手机390/320宽度及键盘交互；V3 账号和 V5 投稿审核继续通过。
- 统计 DB 查询次数和页面加载时间，基线 N=20/100 条，利用 select_related/prefetch_related 消除随作者数量增长的 N+1；报告实际环境和测量结果，不声称生产压测完成。

预期：数据迁移条目全部有成功/人工冲突/失败明细且无人为忽略；切换栏目没有未解决错误。负责人验收前保留原页面，不能以测试通过代替上线授权。

## 8. 回退与下一阶段

栏目切换前保存旧静态快照、准确 SHA 和映射清单。普通展示故障可关闭对应栏目新入口/回退脚本，但已公开修正的隐私内容不能恢复旧静态版；必须用安全占位或保持撤下。保留导入记录和数据库，不按批次级联删除已有投稿。文件与数据库一致备份，不能只退数据库。

交付公共 API、迁移对账、URL 映射、文件安全报告和实际浏览器结果；V7 才处理 AI 候选提取，V8 才据此计算完整看板。
